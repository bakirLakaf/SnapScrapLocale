# SnapScrap — ملاحظات وميزات

## ✅ ما تم إضافته

### قنوات يوتيوب متعددة
- **اختيار القناة** داخل التطبيق قبل الرفع
- **إضافة قناة** (+ إضافة قناة) — يفتح Google OAuth لتسجيل دخول بقناة جديدة
- **تحديث القنوات** (↻) — تحديث أسماء القنوات من يوتيوب
- **ملاحظة OAuth**: أضف في Google Cloud Console → OAuth 2.0 → Authorized redirect URIs:
  - `http://127.0.0.1:5000/youtube/callback`
  - أو `http://localhost:5000/youtube/callback`

### تطبيق الويب
- **قنوات يوتيوب**: عرض قناتك بعد أول ربط (قد تحتاج حذف `token.json` وإعادة التفعيل لرؤية القنوات)
- **رفع على يوتيوب فقط**: تبويب "رفع ملف" لاختيار حساب + ملف ورفعه
- **دمج مزدوج**: Shorts (7..7..7) + فيديو كامل (merged_all) — اختر "الاثنين" في الدمج والرفع
- **رفع الكل**: زر لرفع كل المجلدات المدمجة دفعة واحدة
- **مسح دفعة**: حذف مجلد سنابات بعد الرفع استعداداً للدفعة القادمة

### تيكتوك
- تيكتوك يوفر [Content Posting API](https://developers.tiktok.com/products/content-posting-api)
- تحتاج: إنشاء تطبيق على TikTok for Developers، صلاحية `video.upload`، ربط حساب
- الميزة قيد التطوير — الرابط والشرح موجودان في الواجهة

## ❌ ما لا يمكن تطبيقه بسهولة

### عدم تحميل السنابات التي فيها نساء
- يتطلب **تحليل فيديو بالذكاء الاصطناعي** (كشف وجوه، تصنيف جنس)
- يحتاج نماذج مثل YOLO أو Face API + قاعدة بيانات للتدريب
- معقد ويتطلب موارد كبيرة — غير عملي للتطبيق الحالي

### مراجعة السنابات (قبول/رفض لكل ستوري)
- **قابل للتطبيق** لكن يحتاج واجهة جديدة:
  - عرض كل ستوري قبل الدمج/الرفع
  - أزرار قبول/رفض
  - دمج أو رفع السنابات المقبولة فقط
- يمكن إضافتها لاحقاً كمرحلة ثانية

## 📁 تنظيم الملفات (مستقبلاً)

لتفصل ملفات تطبيق الويب عن تطبيق الحاسوب:
- اقتراح: مجلد `webapp/` لواجهة الويب، وملفات الجذر لـ SnapScrap و merge_videos
- مجلد `accounts/` للسنابات: يمكن إضافة إعداد `accounts_folder` وتحويل المسار إلى `accounts/username/date`

---

## 💰 أرباح رفع السنابات

**رأي عام (ليس استشارة مالية):**
- يوتيوب يدفع من الإعلانات (حوالي 2–5 دولار لكل 1000 مشاهدة تقريباً)
- السنابات المقتطعة من سنابشات قد تواجه قضايا **حقوق نشر** إذا لم تكن أنت صاحب المحتوى
- يوتيوب يطبق سياسات صارمة: محتوى مقتبس بدون إذن قد يُحذف أو تُعلق القناة
- إذا كان المحتوى خاصاً بك أو بموافقة صاحبه، وتعتمد على Shorts وجودة جيدة، الأرباح تعتمد على:
  - عدد المشاهدات والمشتركين
  - معدل الاحتفاظ
  - نوع الإعلانات

**نصيحة**: تحقق من حقوق المحتوى وسياسات يوتيوب قبل الاعتماد على الأرباح.
